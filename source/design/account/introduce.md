
# 账户体系简介

## 账户模型

Geno 的账户体系支持两种账户类型：

1. **外部账户 (Externally Owned Account, EOA)**
    - 由私钥控制，用户通过签名交易发起操作。
    - 不包含任何代码，只有地址、余额和 nonce。
    - 主要用于用户与其他账户或智能合约交互。

2. **合约账户 (Contract Account)**
    - 由智能合约代码控制，没有私钥，代码的执行由交易或消息触发。
    - 包含地址、余额、nonce 和合约代码。

### 账户结构

每个 Geno 账户包含以下四部分：
- **Nonce**: 防止重复交易的计数器，EOA 是交易计数，合约账户是创建合约的次数。
- **余额 (Balance)**: 账户中持有的 Geno 代币数量，以最小单位表示。
- **代码哈希 (CodeHash)**: 智能合约代码的哈希值，外部账户此字段为空。
- **存储哈希 (StorageHash)**: 合约账户的存储根节点哈希值，外部账户为空。

## 地址生成

Geno 地址的生成过程如下：
1. 随机生成私钥（长度取决于选择的加密算法）。
2. 根据选定的加密算法（Ed25519 或 Secp256k1）生成公钥。
    - **Ed25519**：使用 Curve25519 曲线生成密钥对。
    - **Secp256k1**：使用比特币和以太坊等常用的 SECP256k1 曲线生成密钥对。
3. 对公钥进行 Keccak-256 哈希计算。
4. 截取哈希结果的后 20 字节，作为 Geno 地址。

具体生成过程参考[sdk账户生成](https://geno-docs.readthedocs.io/zh-cn/latest/tools/json_rpc/json_rpc_api.html)

地址示例：  
`did:geno:0xabc12345def67890abcdef1234567890abcdef12`

## 加密算法

Geno 支持以下两种加密算法供用户选择：

### 1. **Ed25519**
- 基于 Curve25519 曲线的高效椭圆曲线算法。
- 用途：生成密钥对、签名交易、验证签名。
- 特性：
    - 更快的签名和验证速度。
    - 固定的私钥长度为 256 位。
    - 更高的抗量子攻击能力。

### 2. **Secp256k1**
- 使用的曲线：SECP256k1。
- 用途：生成密钥对、签名交易、验证签名。
- 特性：
    - 私钥为 256 位随机数。
    - 公钥通过 SECP256k1 椭圆曲线计算得到。
    - 常见于比特币和以太坊区块链系统中。

### 3. **Keccak-256 哈希函数**
- 用途：地址生成、交易哈希计算、数据完整性验证。
- 算法：Geno 采用 Keccak-256（SHA-3 的一种变体）。
- 特性：不可逆、抗碰撞。

### 4. **对称加密 (用于账户文件加密)**
- 使用 PBKDF2 或 Scrypt 对私钥加密，增强抗暴力破解能力。
- 账户文件格式：Keystore 文件（JSON 格式），包含加密后的私钥、盐值和其他加密参数。

## 交易签名与验证

### 签名过程
1. 计算交易数据的编码（例如 RLP 编码）。
2. 对编码结果使用 Keccak-256 计算哈希值。
3. 根据选定的加密算法（Ed25519 或 Secp256k1）使用私钥对哈希值签名，生成签名数据。
4. 将签名结果与交易数据一起打包，发送到区块链网络。

### 验证过程
1. 提取交易数据中的签名信息。
2. 根据公钥验证签名是否匹配。
3. 验证通过则认为交易有效。

## 安全注意事项
- **私钥管理**：私钥是账户控制的唯一凭证，必须妥善保管，防止泄露。
- **硬件钱包**：建议使用硬件钱包隔离私钥，提升安全性。
- **多重签名**：对于高价值账户，建议采用多重签名方案以降低风险。

---

通过 Geno 的账户模型与加密算法的灵活支持，用户可以在安全性和性能之间自由选择，同时实现去中心化应用的高效部署。
